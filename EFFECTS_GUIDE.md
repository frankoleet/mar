# 🎨 Гайд по визуальным эффектам

## Доступные эффекты

Сайт включает 7 типов кинематографических эффектов, оптимизированных для мобильных устройств.

---

### ⚡ THUNDER — Молнии и гром
**Для кого:** Thor, Storm, Zeus

**Визуальные эффекты:**
- Случайные молнии с неба
- Синее-белое свечение с размытием
- Тряска экрана (shake animation)

**Звуковые эффекты:**
- thunder.mp3 — раскат грома
- impact.mp3 — удар молнии

**Использование в scenes.json:**
```json
{ "image": "photos/01.jpg", "hero": "THOR", "caption": "Бог грома", "effect": "thunder" }
```

## Специальные эффекты переходов

### Flash — Белая вспышка
Быстрая белая вспышка для резких переходов (молнии, телепортация)

### Glitch — Глитч-эффект
Цифровой сбой с горизонтальными полосами (технологии, порталы)

### Wipe — Энергетический взмах
Светящаяся полоса проходит по экрану (магия, силовые поля)

## Оптимизация производительности

### Автоматическое определение устройства:

**LOW POWER** (слабые телефоны):
- Меньше частиц (10-20 вместо 40)
- Отключены сложные анимации
- Упрощённые эффекты

**MEDIUM POWER** (средние устройства):
- Стандартное количество частиц (20-30)
- Все эффекты включены

**HIGH POWER** (мощные устройства):
- Максимум частиц (40+)
- Ken Burns zoom на фото
- Все эффекты на максимум

### Определение идёт по:
- `navigator.deviceMemory` (RAM)
- `navigator.hardwareConcurrency` (CPU cores)
- User Agent (мобильное устройство или нет)

## Комбинирование эффектов

Вы можете использовать один эффект несколько раз для разных героев:

```json
[
  { "image": "photos/01.jpg", "hero": "THOR", "effect": "thunder" },
  { "image": "photos/05.jpg", "hero": "THOR", "effect": "thunder" },
  { "image": "photos/02.jpg", "hero": "CAPTAIN AMERICA", "effect": "shield" },
  { "image": "photos/04.jpg", "hero": "AVENGERS", "effect": "ironman" }
]
```

## Создание собственных эффектов

Хотите добавить свой эффект? Редактируйте `js/effects.js`:

1. Добавьте новую функцию в `EffectsEngine` class
2. Добавьте case в метод `play()`:
   ```javascript
   case 'myeffect': this.myeffect(); break;
   ```
3. Используйте в scenes.json:
   ```json
   { "effect": "myeffect" }
   ```

## Вибрация (Haptic Feedback)

На поддерживаемых устройствах (Android Chrome) мощные эффекты вызывают вибрацию:

- Thunder ⚡ → [30ms, пауза, 50ms, пауза, 30ms]
- Shield 🛡️ → [30ms, пауза, 50ms, пауза, 30ms]
- Hulk 💚 → [30ms, пауза, 50ms, пауза, 30ms]

## Доступность

### Prefers Reduced Motion
Если пользователь включил "Уменьшение движения" в настройках системы:
- Отключаются все анимации
- Убирается тряска экрана
- Эффекты становятся статичными (opacity 25%)
- Comic flip не показывается

### Тёмный режим
Сайт по умолчанию использует тёмную тему, оптимизированную для просмотра в любых условиях.

## Troubleshooting

**Эффекты лагают:**
- Это нормально на старых телефонах — система автоматически упрощает
- Можно уменьшить размер фотографий (до 1200px)
- Включите "Уменьшение движения" в настройках телефона

**Эффекты не показываются:**
- Откройте консоль браузера (F12) и проверьте ошибки
- Убедитесь, что `effects.js` загружен
- Проверьте правильность названия эффекта в `scenes.json`

**Canvas не работает:**
- Убедитесь, что браузер поддерживает Canvas API
- Попробуйте другой браузер (Chrome, Firefox, Safari)
