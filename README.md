# МИША — Cinematic Surprise Website

Кинематографический сайт-сюрприз для ребёнка в стиле Marvel/Avengers. Полностью работает офлайн, оптимизирован для мобильных устройств.

## 🚀 Быстрый старт

1. **Замените фотографии** в папке `/photos/` на свои (01.jpg - 10.jpg)
2. **Откройте** `index.html` в браузере
3. **Готово!** Сайт работает локально без сервера

## 🖼️ Как заменить фотографии

### Способ 1: Простая замена
1. Подготовьте **10 фотографий** формата JPG
2. Переименуйте их в `01.jpg`, `02.jpg` ... `10.jpg`
3. Скопируйте в папку `/photos/`, заменив существующие

### Способ 2: Свои названия
1. Положите фотографии в `/photos/`
2. Откройте `scenes.json`
3. Измените пути в поле `"image"`:

```json
[
  { "image": "photos/misha-birthday.jpg", "hero": "THOR", ... },
  { "image": "photos/misha-park.jpg", "hero": "CAPTAIN AMERICA", ... }
]
```

### Рекомендации по фото:
- **Формат:** JPG или PNG
- **Размер:** оптимально 1200-1920px по ширине
- **Соотношение:** желательно вертикальные или квадратные
- **Вес:** до 500KB каждое для быстрой загрузки

## ⚙️ Настройка сцен (scenes.json)

Каждая сцена имеет 4 параметра:

```json
{
  "image": "photos/01.jpg",      // путь к фото
  "hero": "THOR",                // имя героя (большими буквами)
  "caption": "Бог грома Миша",   // подпись под именем
  "effect": "thunder"            // визуальный эффект
}
```

### Доступные эффекты:
- **thunder** — молнии и гром (Тор)
- **shield** — искры от удара щита (Капитан Америка)
- **panther** — фиолетовые частицы (Чёрная пантера)
- **embers** — летящие угольки
- **hulk** — зелёная энергетическая волна
- **ironman** — голубое репульсорное свечение
- **magic** — вращающиеся мандалы (Доктор Стрэндж)

### Добавление/удаление сцен:
Просто добавьте или удалите объекты в массиве. Количество сцен не ограничено.

```json
[
  { "image": "photos/01.jpg", "hero": "THOR", "caption": "Миша — герой!", "effect": "thunder" },
  { "image": "photos/02.jpg", "hero": "HULK", "caption": "Невероятная сила", "effect": "hulk" }
]
```

## 🔊 Добавление аудио (опционально)

Сайт работает и без звука, но с ним атмосфернее!

### Что нужно:
Добавьте 4 MP3-файла в папку `/audio/`:
- `music.mp3` — эпическая фоновая музыка (2-4 мин, loop)
- `thunder.mp3` — звук грома для эффекта Тора (1-2 сек)
- `whoosh.mp3` — свист для магии и полётов (0.5-1 сек)
- `impact.mp3` — мощный удар для импакта (0.5-1 сек)

### Бесплатные источники:
- **Pixabay**: https://pixabay.com/sound-effects/
- **Mixkit**: https://mixkit.co/free-sound-effects/
- **Freesound**: https://freesound.org/

## 🌐 Публикация в интернет

### Vercel (рекомендуется)
1. Создайте аккаунт на [vercel.com](https://vercel.com)
2. Установите Vercel CLI: `npm i -g vercel`
3. В папке проекта выполните: `vercel`
4. Или просто перетащите папку в веб-интерфейс Vercel
5. Готово! Получите ссылку вида `https://misha-hero.vercel.app`

### GitHub Pages
1. Создайте репозиторий на GitHub
2. Загрузите все файлы
3. Settings → Pages → выберите ветку `main`
4. Сайт доступен по адресу `https://username.github.io/repo-name`

### Cloudflare Pages / Netlify
Аналогично Vercel — просто перетащите папку или подключите GitHub.

## 🎨 Кастомизация

### Изменить имя ребёнка
Откройте `index.html` и найдите:
```html
<h1 class="name-logo">МИША<span class="logo-shine"></span></h1>
```
Замените `МИША` на нужное имя (БОЛЬШИМИ БУКВАМИ).

Также найдите все упоминания "Миша" по тексту и замените.

### Изменить цвета
Откройте `css/style.css` и измените переменные в `:root`:
```css
:root{
  --red:#ed1d24;        /* Основной красный */
  --cream:#fff4df;      /* Цвет текста */
  --gold:#e9b66e;       /* Золотой акцент */
  --accent:#72caff;     /* Голубой акцент */
}
```

### Добавить логотип
Замените `favicon.svg` на свой файл с тем же именем.

## 🐛 Решение проблем

**Фото не загружаются**
- Проверьте пути в `scenes.json`
- Убедитесь, что файлы существуют в `/photos/`
- Проверьте регистр имён файлов (case-sensitive на Linux)

**Звук не работает**
- Убедитесь, что файлы есть в `/audio/`
- Первое воспроизведение требует клика пользователя (ограничение браузеров)
- Проверьте консоль браузера (F12) на ошибки

**Эффекты тормозят**
- Нормально для старых телефонов — автоматически упрощаются
- Уменьшите размер фотографий (сожмите до 1200px)

**Сайт не открывается с телефона**
- Убедитесь, что все файлы на одном уровне с `index.html`
- Проверьте права доступа к файлам
- Попробуйте другой браузер
